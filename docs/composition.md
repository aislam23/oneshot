# Композиция: API `OS.film`

Ролик — одна страница `comp.html` в папке, созданной `oneshot new`:

```
film/
  comp.html        ← ролик
  vendor/          ← gsap.min.js и oneshot.js (кладёт `oneshot new`)
  vo/lines.txt     ← текст диктора
  vo/plan.js       ← партитура (создаёт `oneshot vo plan`)
  fonts.css        ← шрифты внутри файла (`oneshot fonts`)
```

Структура страницы: `#stage` (экран 1920×1080) → `#ground` (фон с сеткой, едет медленнее камеры) → `#world` (мир, его двигает камера).
Всё, что должно ехать с камерой, кладите в `#world`. Подписи «поверх экрана» — прямо в `#stage`.

## Скелет

```html
<script src="vendor/gsap.min.js"></script>
<script src="vendor/oneshot.js"></script>
<script src="vo/plan.js"></script>
<script>
const F = OS.film({ duration: VO.total });            // длина = из партитуры
F.place('#dot', { x: 940, y: 520, w: 40, h: 40, r: 20 });
F.pop('#dot', 0.2);
F.morph('#dot', F.W(1, 'первый'), 0.6, { x: 560, y: 610, w: 800, h: 10, r: 5 });
F.camera([{ t: 0, x: 960, y: 540, zoom: 1 }, { t: F.L(3) + 0.8, x: 2400, y: 520, zoom: 1.2, ease: 'expo.inOut' }]);
F.thread('dot'); F.beat(0, 'начало'); F.beat(F.L(2), 'вторая сцена', { thread: 'dot' });
F.expose();
</script>
```

## Время из голоса

| вызов | что даёт |
|---|---|
| `F.L(n)` | начало фразы n (с 1) |
| `F.E(n)` | конец фразы n |
| `F.W(n, 'слово', k=1)` | время k-го слова фразы n, в котором есть подстрока `'слово'` |
| `VO.total` | длина ролика |

Время слов внутри фразы — оценка по длине букв и знакам препинания (точность ~0,1–0,2 с). Для ударных моментов этого хватает;
если нужно точнее, ставьте событие на начало фразы.

## Движение

| вызов | что делает |
|---|---|
| `F.place(el, {x,y,w,h,r})` | ставит элемент (абсолютные px мира) |
| `F.pop(el, t, {y, from, rot, dur, ease})` | появление с пружинкой (по умолчанию `back.out(1.8)`) |
| `F.rise(el, t, …)` | появление снизу без пружины (`expo.out`) — для текста |
| `F.leave(el, t, {y, to, dur})` | уход |
| `F.morph(el, t, dur, {x,y,w,h,r}, ease)` | элемент меняет место, размер и скругление — главный инструмент нити |
| `F.to(el, t, vars)` | любой твин GSAP в нужный момент (`{ x: 120, duration: .5, ease: 'power3.out' }`, `keyframes`, `backgroundColor`…) |
| `F.popEach(sel, times, …)` | детей по очереди, каждого в своё время |
| `F.tl` | сам таймлайн GSAP — для всего остального (`F.tl.fromTo(..., t)`) |

GSAP-твины, начинающие с `from`-состояния, пишите с `immediateRender: false` и задайте исходное состояние через `gsap.set` —
так кадр в любой момент получается одинаковым, в каком бы порядке ни перематывали.

## Текст, счётчики, курсор — сегменты

Всё, что нельзя выразить твином (текст, числа, путь курсора), — **сегменты**: чистые функции времени.

| вызов | что делает |
|---|---|
| `F.type(el, t, 'текст' \| [[cls, текст], …], {cps, caret})` | печать с курсором; части с классом (`'lnk'`) — для подсветки |
| `F.text(el, t, html)` | заменить содержимое в момент t |
| `F.count(el, t, dur, a, b, {format})` | число растёт от a до b |
| `F.cursor(el, {path:[{t,x,y,ease}], clicks:[t], show:[[t0,t1]]})` | курсор мыши по точкам, нажатия; можно вызывать несколько раз |
| `F.seg(key, t0, t1, (k, t, tRaw) => …)` | свой сегмент: k — прогресс 0…1, t — время в отрезке, tRaw — время кадра |

Сегменты одного элемента не спорят: активен последний начавшийся, до первого — состояние первого в начале.
Так, `F.text('#btn', 0, 'Нажми'); F.text('#btn', 5, 'Готово')` работает в обе стороны перемотки.

## Камера

```js
F.camera([
  { t: 0,    x: 960,  y: 540, zoom: 1 },                         // (x, y) — точка мира в центре кадра
  { t: 4.2,  x: 960,  y: 540, zoom: 1 },                         // стоит, пока говорят
  { t: 5.0,  x: 2600, y: 500, zoom: 1.3, ease: 'expo.inOut' },  // переезд между фразами; ease — как камера ПРИХОДИТ в ключ
]);
F.handheld([[10, 25]], 3);   // «рука оператора» в отрезке, амплитуда в px экрана
F.shake(12.4, 10);           // толчок при ударе
```

Приёмы: удерживайте ключ до конца фразы (`{t: F.E(n), …}`), переезд — 0,5–0,9 с; на резкий переброс — `expo.inOut`,
на плавный — `power3.inOut`; масштаб интерполируется логарифмически, поэтому зум 0,1 → 3 идёт равномерно.
`F.toScreen(x, y, t)` — где точка мира окажется на экране.

## Разметка для проверки и звука

| вызов | зачем |
|---|---|
| `F.beat(t, 'имя', {thread, cut})` | граница сцены; `thread` — id элемента-нити; `cut: true` — осознанная склейка (её не размывает рендер) |
| `F.thread(id)` | элемент, который может быть нитью (контейнер нулевого размера меряется по содержимому) |
| `F.keep(el, t0, t1)` | элемент обязан быть в кадре в этот отрезок |
| `F.sound(t, kind, {x, gain, f, dur})` | звук: `whoosh pop tick click key thump rise chord swell`; x — точка мира (панорама), f — высота |
| `F.ready(promise)` | дождаться чего-то своего перед рендером |
| `F.expose()` | опубликовать `window.oneshot` — обязательно в конце |

## Превью

- `comp.html?play` — проигрывание в реальном времени (`&from=40` — с 40-й секунды);
- `comp.html?t=12.5&hud` — один кадр и счётчик времени.

## Вертикальное видео

`OS.film({ duration, width: 1080, height: 1920 })` и такие же размеры `html, body` в CSS. Рендер и проверка читают размер из страницы.
