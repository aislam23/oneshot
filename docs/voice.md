# Голос: текст диктора, ElevenLabs, субтитры

## Как писать текст

- Одна фраза — одна мысль, 6–14 слов. Длинное предложение режьте на два.
- Глагол раньше подробностей: «Установка — одна команда», а не «Для установки вам понадобится выполнить одну команду».
- Темп живой речи ≈ 2,3 слова в секунду. 90 секунд ≈ 180–200 слов с паузами.
- Слова, на которых что-то появится на экране, ставьте ближе к концу фразы — там ударение.
- Без канцелярита и длинного тире в субтитрах, если бренд его не любит; цифры — так, как удобно читать на экране (1080p, 4K).

## `vo/lines.txt`

```
# комментарий
Хорошее видео звучит как музыка.
Вы пишете текст диктора,|а агент раскладывает его в партитуру.

Установка — одна команда.
```

- `|` — граница карточек субтитров внутри фразы;
- пустая строка — пауза подлиннее (+0,5 с);
- `vo/say.txt` — те же строки «как слышится», для чернового голоса: `Клод Код`, `эйч-ти-эм-эль`, `джи-сап`, `четыре-ка`.

`oneshot vo plan vo/lines.txt --say vo/say.txt --duration 90 [--speed 0.9] [--gap 0.4]`
создаёт `plan.js`, `plan.json`, `guide.wav`, `subtitles.srt` и `subtitles.md` (таблица для сценария).
Без macOS команды `say` нет — тайминг оценивается по длине текста, черновой голос не создаётся.

## Текст для ElevenLabs (модель Eleven v3)

Теги в квадратных скобках задают подачу: `[confident] [calm] [warm] [excited] [curious] [playful] [serious] [sarcastic]
[impressed] [whispers] [sighs] [laughs]`, паузы — `[short pause]`, `[pause]` и многоточие. Правила:

1. Тег ставится в начале фразы и действует до следующего тега. Один-два тега на фразу, не больше.
2. Названия пишите так, как их надо произнести: «Ван-шот», «Клод Код», «ГитХаб», «эйч-ти-эм-эль».
3. Каждая фраза — с новой строки: так ElevenLabs делает паузу, и `oneshot vo audio` потом найдёт границы фраз.
4. Важное слово можно выделить ПРОПИСНЫМИ — модель сделает на нём ударение. Не злоупотребляйте.

```
[confident] Хорошее видео звучит как музыка.
[warm] Каждое движение попадает в слово.
[short pause]
[excited] Так работает Ван-шот — скилл для Клод Код и Кодекс.
```

## Озвучка готова — перестройте ролик под неё

```bash
oneshot vo audio vo/lines.txt voice.mp3       # тайминг из настоящего голоса → vo/plan.js, субтитры, волна
oneshot render comp.html --audio mix.wav      # ролик сам встанет на новые слова
```

Скрипт ищет паузы в голосе и берёт самые длинные как границы фраз. Если фраз нашлось меньше, чем строк, —
сделайте паузы между фразами длиннее (перенос строки или `[short pause]` в ElevenLabs) или понизьте порог `--threshold -42`.
Он предупредит, если длительность какой-то фразы сильно не соответствует длине её текста.

## Сведение

`oneshot mix --voice voice.mp3 --sfx sfx.wav --music music.mp3 --out mix.wav`
— голос на полной громкости, звуки как есть (они уже на −14 дБ), музыка приглушается каждый раз, когда звучит голос.
Музыку берите только с лицензией на использование (YouTube Audio Library, Pixabay Music, NCS) и храните ссылку на источник.
