# Партитура — антипример

Тот же урок про oneshot, концепт «Партитура»: ось мира — время голоса, ключевые слова — ноты на стане, из каждой ноты
вырастает объект. Технически всё чисто: каждое движение стоит на слове, у каждого перехода есть нить, текст крупный.

И всё равно ролик скучный. Почему — `oneshot check` говорит прямо:

```
 ПРОВАЛ  однообразие 48 разных жестов; чаще всего «нота вспыхивает» — 72 раз
 ВНИМ.   камера     87 % переездов — вправо: камера листает, а не снимает
```

- **Один жест по кругу.** «Нота вспыхнула → вырос штиль → выпрыгнул объект» — к третьей сцене зритель угадывает следующую.
- **Камера листает.** Страница за страницей вправо, почти без смены масштаба.
- **Мелкие значки** над большой волной вместо крупного интерфейса и слов.
- **Нет героя и кульминаций**: ничто не превращается, все сцены одного веса.

Сравните с `examples/slovo` — тот же текст по смыслу, но у каждой сцены свой жест, герой превращается, камера ныряет.
Урок: концепт, который сводится к одному повторяющемуся механизму, даёт узор, а не развитие.
