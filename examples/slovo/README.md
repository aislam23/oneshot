# Слово становится вещью — эталонный пример

Урок про oneshot на 90 секунд. Материал ролика — слова диктора, набранные огромным шрифтом: каждое ключевое слово
превращается в то, что называет. Светлая тема islamov-tema.ru.

| сцена | жест | нить дальше |
|---|---|---|
| СЛОВО → фигуры | буквы падают с отскоком, потом сжимаются в круг, треугольник, кольцо, квадрат, точку | фигуры |
| ONESHOT | фигуры сходятся в точку и взрываются словом | камера |
| нырок в О | камера влетает в букву О (×32), внутри — ролик и волна голоса | камера |
| Claude Code, Codex | отъезд; слова влетают с разных сторон с толчком | слова падают вниз |
| текст → секунды | фраза печатается, слова разлетаются по линейке времени | линейка |
| каждое на слове | курсор времени, слова подпрыгивают | «слово» вырастает |
| HTML, GSAP | перебор символов слово → `<HTML>` → `GSAP`, дорожки анимации | надпись |
| кадр за кадром | плёнка бежит вправо, камера едет за ней | плёнка |
| РАЗМЫТИЕ | слово пролетает со смазом и вышибает плёнку | слово |
| установка | буквы осыпаются, УСТАНОВКА поднимается из-под маски, курсор печати вырастает в терминал | курсор |
| команда | камера ведёт строку печати | терминал |
| через агента | терминал превращается в чат, курсор жмёт «отправить» | камера-переброс |
| пять правил | огромная 5, затем цифра крутится как счётчик 1…5 | цифра |
| правила 1–3 | голос → волна, текст → картинка; три карты, выбор одной; слово разрезано, сцена вырастает из половинки | цифра |
| правило 4 | УДАР. УДАР. — две честные склейки, чёрный фон, тишина, ПАУЗА медленно расходится | чёрный фон |
| правило 5 | чёрный фон сжимается в черновик 1080P, чек-лист, черновик вырастает во весь кадр 4K | кадр |
| финал | печать БЕСПЛАТНО, кадр сжимается в строку со ссылкой, фигуры из первого кадра собирают имя | — |

`oneshot check`: 20 переходов с нитью, ритм 0,41, 72 разных жеста (самый частый — 6 раз), масштаб камеры ×36, текст ≥ 22 px.
