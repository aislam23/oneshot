# oneshot

Ролик — это одна HTML-страница, где всё время берётся из голоса диктора. Агент пишет текст, раскладывает его
в **партитуру** (секунда каждой фразы и слова), придумывает картинку, привязывает каждое движение к слову,
рендерит видео кадр за кадром и проверяет его до того, как покажет человеку.

Скилл живёт в своей папке (`~/.claude/skills/oneshot` или `~/.agents/skills/oneshot`). Команда — `node <папка>/bin/oneshot.mjs …`,
дальше в тексте просто `oneshot …`. Подробности: `docs/` (метод, композиция, голос, рендер и проверка, грабли).

## Когда этот скилл

- Объясняющее видео, урок, промо продукта / бота / приложения / скилла, тизер, ролик под озвучку — **да**.
- Демо интерфейса без записи экрана: интерфейс пересобирается в HTML по скриншотам — **да**.
- Монтаж живого видео, говорящая голова, нарезка подкаста — **нет**, скажи об этом.

## Протокол — по порядку, без пропусков

### 0 · Окружение
`oneshot doctor`. Если чего-то нет — поставь (или скажи пользователю команду). Первый запуск после установки:
`cd <папка скилла> && npm install && npx playwright install chromium`.

### 1 · Бриф — коротко
Узнай только то, чего нет в файлах: о чём ролик и для кого, где его покажут (YouTube, Reels — тогда 1080×1920), длина,
чей голос (ElevenLabs, свой, без голоса), стиль (сайт, брендбук, `Design.md` — поищи сам в проекте). Не больше 4 вопросов за раз.

### 2 · Голос раньше картинки
1. Напиши текст диктора в `vo/lines.txt`: одна фраза — одна строка, одна мысль на фразу, 6–14 слов.
   `|` делит фразу на две карточки субтитров, пустая строка — пауза подлиннее. Темп живой речи ≈ 2,3 слова в секунду.
2. Если в тексте латиница или аббревиатуры, сделай `vo/say.txt` — те же строки «как слышится» (Клод Код, эйч-ти-эм-эль).
3. `oneshot vo plan vo/lines.txt --say vo/say.txt --duration <сек>` → `vo/plan.js` (тайминг фраз и слов),
   `vo/guide.wav` (черновой голос, macOS), `vo/subtitles.srt`, волна голоса.
4. Не влезает в длину — правь текст или `--speed 0.9…1.1`. Никогда не растягивай паузы, чтобы заполнить время.
5. Если пользователь уже записал озвучку: `oneshot vo audio vo/lines.txt voice.mp3` — тайминг возьмётся из настоящего голоса.

### 3 · Три концепта — пользователь выбирает
Концепт — одна фраза о **картинке**, а не о продукте: из чего сделан весь ролик и что тянется через все сцены (нить).
Предложи три, непохожих по главной идее (не три истории на одних и тех же карточках). Для каждого: первый кадр,
**герой, который превращается** через весь ролик, 3–4 коронных момента (нырок, удар, тишина, сборка), грамматика камеры,
что концепт запрещает, стиль. Спроси выбор (AskUserQuestion).
Концепт, который сводится к одному повторяющемуся механизму («каждое слово — нота»), отбрасывай сразу: он даст узор, а не развитие.
Шаблон из `oneshot new` — это пример API, а не концепт; не делай ролик «по шаблону».

### 4 · Партитура сцен
Таблица до кода: `время (фраза, слово) · что появляется · что движется · что стоит · нить в следующую сцену`.
- Каждый объект — на своём слове (`F.W(фраза, 'слово')`). Без слова объекту в кадре делать нечего.
- Камера стоит, пока говорят, и переезжает между фразами. Исключение — осознанное «ведение» объекта.
- Сцены разной длины: короткие удары рядом с длинными. Нужны передышки — секунды, где кадр почти не меняется.
- **У каждой сцены свой жест.** Выпиши столбик жестов; один жест — не больше 3–4 раз за ролик. Главный объект — 40–70 % ширины кадра.
- **Камера снимает, а не листает:** перепад масштаба ×3+, нырок внутрь объекта, переброс, смена направления.
- На каждой границе сцен назови, что переживает её и меняется: элемент вырастает в следующий (`F.morph`),
  камера въезжает внутрь, курсор ведёт к следующему. «Погасло — появилось новое» — это склейка, она разрешена только
  как осознанный приём (`F.beat(t, name, { cut: true })`).

### 5 · Композиция
`oneshot new film/` → `film/comp.html`, `vendor/`, `vo/`. Шрифты: `oneshot fonts "Golos Text:400;600" --out film/fonts.css`.
Цвета и шрифты — переменными в `:root`. Код — на API `OS.film` (`docs/composition.md`): `F.pop / F.rise / F.leave / F.morph /
F.type / F.cursor / F.camera / F.seg`, разметка `F.beat / F.thread / F.keep / F.sound`, в конце `F.expose()`.
Правило детерминизма: всё меняется только через таймлайн и сегменты — без `setTimeout`, `requestAnimationFrame`,
`Date`, `Math.random` в коде ролика. `oneshot.seek(t)` в любом порядке должен давать тот же кадр.

### 6 · Посмотри сам, прежде чем рендерить
`oneshot stills film/comp.html --times …` — 6–12 моментов (начало каждой сцены, переходы, финал) и **открой картинку**.
Обрезанный текст, пустые кадры, наложения, мелочь — правь сразу. Превью в браузере: `comp.html?play`, кадр: `?t=12.5&hud`.

### 7 · Проверка композиции
`oneshot check film/comp.html`. ПРОВАЛ — исправить: переход без нити, объект вылетел из кадра (`F.keep`), текст мельче
16 px на экране, один жест повторён больше 20 раз, ошибки страницы. ВНИМАНИЕ — оцени и объясни пользователю, почему оставил
(однообразие 12–20 повторов, камера «листает», ровный ритм).

### 8 · Звук и черновик
`oneshot sfx film/comp.html --out film/sfx.wav` (звуки из `F.sound`, пик −14 дБ под голос).
С голосом: `oneshot mix --voice voice.mp3 --sfx sfx.wav [--music m.mp3] --out mix.wav` (музыка приглушается под голос).
`oneshot render film/comp.html --out draft.mp4 --audio sfx.wav` — 1080p30, размытие движения.
`oneshot check film/comp.html --video draft.mp4` — и только потом показывай.

### 9 · Финал — после «да»
`oneshot render film/comp.html --final --out final.mp4 --audio mix.wav` — 4K60. Никогда до утверждения черновика.

### 10 · Что отдать
Видео, `vo/subtitles.srt`, текст для ElevenLabs с тегами (`docs/voice.md`), версию с черновым голосом для сверки тайминга
(`draft.mp4` + `vo/guide.wav` через `oneshot mix`). Скажи, где речь кончается и сколько тишины в конце.

## Жёсткие правила

- **Голос раньше картинки.** Сначала текст и `vo plan`, потом сцены. Время в коде — только через `F.L / F.E / F.W`.
- **Ни одного объекта без слова.** Появление, смена, нажатие стоят на слове диктора.
- **Превращение, а не подмена.** Следующая сцена вырастает из элемента предыдущей. Склейка — только осознанно и с `cut: true`.
- **Камера стоит, пока говорят.** Переезд — между фразами, с ускорением и торможением (`power3.inOut`, `expo.inOut`).
- **Разная длина сцен и передышки.** Одинаковые сцены подряд читаются как слайды.
- **Развитие, а не узор.** Один жест — не больше 3–4 раз. Герой превращается, у ролика есть кульминации. Пример провала — `examples/partitura`.
- **Крупно.** Главный объект сцены занимает 40–70 % ширины кадра; настоящий интерфейс и слова, а не пиктограммы.
- **Мелкое на большом поле — но текст ≥ 22 px на экране.** Ролик смотрят с телефона.
- **Одна идея картинки на ролик.** Концепт выбирает пользователь из трёх.
- **Черновик 1080p30, финал 4K60 только после согласия.**
- **Звуки тише голоса и реже событий.** Одна «комната», не по звуку на каждый чих.
- **Не выдумывать.** Цифры, отзывы, клиентов, чужие логотипы — только реальные и с разрешения.
- **Детерминизм.** Без случайности и реального времени в коде ролика; шум — только из `seed`.

## Файлы

| путь | что это |
|---|---|
| `bin/oneshot.mjs` | все команды: doctor, new, fonts, vo, stills, sfx, mix, render, check |
| `lib/oneshot.js` | браузерная библиотека `OS.film` поверх GSAP (копируется в `film/vendor/`) |
| `lib/render.mjs` | рендер: параллельные браузеры, размытие движения через усреднение подкадров (ffmpeg `tmix`) |
| `lib/vo.mjs` | партитура от голоса: тайминг фраз и слов, черновой голос, волна, субтитры, тайминг по готовой озвучке |
| `lib/check.mjs` | проверка: нить, ритм, однообразие, камера, кадр, текст, передышки, длина, звук |
| `lib/sfx.mjs` | синтезатор звуков и сведение с голосом и музыкой |
| `lib/tools.mjs` | stills, fonts, doctor, new |
| `templates/film/` | стартовый ролик на 3 фразы — пример API |
| `examples/slovo/` | **эталон**: урок про oneshot, 90 с, концепт «Слово становится вещью» — у каждой сцены свой жест |
| `examples/partitura/` | **антипример**: тот же урок, концепт «Партитура» — технически чисто, но скучно; `check` ловит однообразие |
| `docs/method.md` | метод: голос, концепт, партитура, нить, ритм |
| `docs/composition.md` | API `OS.film`, камера, детерминизм |
| `docs/voice.md` | как писать текст диктора, теги ElevenLabs, субтитры, перезапись озвучки |
| `docs/render-check.md` | рендер, размытие, 4K, что проверяет `check` |
| `docs/pitfalls.md` | грабли, на которые уже наступили |
