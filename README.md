# oneshot

**Скилл для ИИ-агентов, который делает ролики под голос.** Вы даёте тему, агент пишет текст диктора, раскладывает его
по секундам, придумывает картинку и собирает видео на HTML + GSAP, где каждое движение попадает в слово, а сцены
перетекают друг в друга без склеек. На выходе — mp4, субтитры, текст для ElevenLabs с тегами эмоций и звуки.

Работает с **Claude Code**, **Codex** и другими агентами, которые читают скиллы.

## Что умеет

- **Партитура от голоса.** Текст диктора → тайминг каждой фразы и слова → анимация стоит на словах.
  Перезаписали озвучку — одна команда, и ролик перестраивается под новый голос.
- **Ролик одним дублем.** Следующая сцена вырастает из предыдущей; проверка ловит переходы-«склейки».
- **Настоящее размытие движения.** Рендер кадр за кадром, 1080p30 для черновиков, 4K60 для финала.
- **Звук.** Встроенный синтезатор щелчков, «вжухов» и нот в одной комнате; сведение с голосом и музыкой, музыка уходит под голос.
- **Субтитры и голос.** `.srt`, черновой голос для сверки тайминга (macOS), правила текста для ElevenLabs v3.
- **Проверка до показа.** Нити на переходах, ритм, объекты в кадре, мелкий текст, передышки, громкость.
- **Ваш стиль.** Цвета — переменными, шрифты Google встраиваются одной командой.

## Установка

### Вариант 1 — командой

```bash
# Claude Code
git clone https://github.com/aislam23/oneshot.git ~/.claude/skills/oneshot
# Codex и другие агенты
git clone https://github.com/aislam23/oneshot.git ~/.agents/skills/oneshot

cd ~/.claude/skills/oneshot      # или ~/.agents/skills/oneshot
npm install
npx playwright install chromium
```

Нужны **Node.js 18+** и **ffmpeg** (macOS: `brew install ffmpeg`, Windows: `winget install ffmpeg`, Linux: `sudo apt install ffmpeg`).
Проверить всё разом: `node ~/.claude/skills/oneshot/bin/oneshot.mjs doctor`.

### Вариант 2 — попросите агента

Напишите своему агенту:

> Установи скилл https://github.com/aislam23/oneshot — склонируй его в папку скиллов, поставь зависимости и проверь `oneshot doctor`.

### Вариант 3 — архивом

Скачайте архив репозитория, распакуйте в `~/.claude/skills/oneshot` и выполните `npm install && npx playwright install chromium` внутри папки.

## Как пользоваться

Просто попросите агента:

- «Сделай 60-секундный ролик про мой Telegram-бот, стиль возьми с сайта»
- «Объясняющее видео на полторы минуты для урока про GitHub, под озвучку ElevenLabs»
- «Вот моя озвучка `voice.mp3` — перестрой ролик под неё»
- «Ролик выглядит как презентация — переделай без склеек»

Агент пройдёт протокол: бриф → текст диктора и тайминг → три концепта на выбор → партитура сцен → кадры на проверку →
черновик → ваше «да» → финал в 4K.

## Лучшие практики

1. **Начинайте с голоса.** Сначала текст и тайминг, потом картинка.
2. **Выбирайте из трёх концептов.** Одна идея картинки на весь ролик — и её выбираете вы.
3. **Никаких склеек.** Что-то из прошлой сцены всегда переходит в следующую.
4. **Меняйте темп.** Короткие удары рядом с длинными паузами.
5. **Черновик и проверка — до финала.** 4K рендерится только после утверждения.

## Пример

`examples/oneshot-intro/` — урок про сам oneshot на 90 секунд (концепт «Партитура»). Собрать его у себя:

```bash
cd ~/.claude/skills/oneshot/examples/oneshot-intro
node ../../bin/oneshot.mjs vendor .
node ../../bin/oneshot.mjs vo plan vo/lines.txt --say vo/say.txt --speed 0.9 --gap 0.4 --duration 90
node ../../bin/oneshot.mjs sfx comp.html --out sfx.wav
node ../../bin/oneshot.mjs render comp.html --out draft.mp4 --audio sfx.wav
node ../../bin/oneshot.mjs check comp.html --video draft.mp4
```

## Команды

```
oneshot doctor                      проверить окружение
oneshot new <папка>                 новый ролик из шаблона
oneshot vendor <папка>              обновить gsap и oneshot.js в папке ролика
oneshot fonts "Golos Text:400;600"  шрифты Google внутрь fonts.css
oneshot vo plan vo/lines.txt        тайминг от текста, черновой голос, субтитры
oneshot vo audio vo/lines.txt v.mp3 тайминг по готовой озвучке
oneshot stills comp.html --times …  контактный лист кадров
oneshot sfx comp.html               звуки из событий ролика
oneshot mix --voice … --sfx …       сведение голоса, звуков и музыки
oneshot render comp.html            черновик 1080p30 (--final — 4K60)
oneshot check comp.html             проверка до показа
```

Документация: [`SKILL.md`](SKILL.md) (протокол для агента), [`docs/`](docs) — метод, API, голос, рендер, грабли.
